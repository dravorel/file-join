# File Join

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![Code Style](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)

CLI-утилита на Python для объединения файлов.

Утилита работает с бинарными файлами, поддерживает объединение отдельных файлов,
обработку содержимого директорий, поиск файлов по шаблону с использованием `*`, 
отображение прогресса выполнения и интерактивное подтверждение добавления данных 
в существующий файл.

## 🛠️ Установка

1. Клонируйте репозиторий:
    ```bash
    git clone <url>
    cd <project-directory>
    ```

2. Создайте виртуальное окружение (опционально):
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # Для Linux/Mac
    .venv\Scripts\activate     # Для Windows
    ```

3. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 Использование

Запуск из корня проекта:

```bash
python main.py [-h] -o OUTPUT [-y] input [input ...]
```

| Короткий параметр | Полный параметр | Тип    | По умолчанию      | Описание                                                                                                          | Пример                |
|-------------------|-----------------|--------|-------------------|-------------------------------------------------------------------------------------------------------------------|-----------------------|
| —                 | —               | `str`  | **обязательный**  | Один или несколько входных файлов, директорий или шаблонов имён файлов. Файлы объединяются в порядке их передачи. | `part1.bin part2.bin` |
| `-o`              | `--output`      | `str`  | **обязательный**  | Путь к выходному файлу.                                                                                           | `-o output.bin`       |
| `-y`              | `--yes`         | `bool` | `False`           | Не запрашивать подтверждение при добавлении данных в существующий выходной файл.                                  | `-y`                  |


## 📄 Поддерживаемые входные данные

- **Отдельные файлы:** можно указать несколько файлов для последовательного объединения.
- **Директории:** можно указать директорию для добавления всех находящихся в ней файлов (без рекурсивного обхода).
- **Шаблоны:** поддерживается символ `*` в имени файла. Он используется для поиска файлов, содержащих одну или несколько цифр на соответствующей позиции.

## 💡 Примеры

1. Объединить два файла в один:
   ```bash
    python main.py part1.bin part2.bin -o output.bin
   ```
   
2. Объединить все файлы из директории:
   ```bash
    python main.py ./parts -o output.bin
   ```
   
3. Объединить файлы по шаблону имени:
   ```bash
    python main.py "./parts/file-*.bin" -o output.bin
   ```
   
4. Объединить отдельные файлы и содержимое директории:
   ```bash
    python main.py part1.bin ./parts part2.bin -o output.bin
   ```
   
5. Добавить данные в существующий файл без подтверждения:
   ```bash
    python main.py part1.bin part2.bin -o output.bin -y
   ```
